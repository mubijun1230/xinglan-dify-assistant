# 反商业贿赂、利益冲突与礼品招待规定

文件编号：XL-CG-004  
版本：V3.1  
生效：2026-01-01  
归口：法务合规部

## 1. 原则

南极人禁止任何形式的商业贿赂。员工不得为获取订单、验收、付款而给予或收受不正当利益，包括回扣、购物卡、虚拟货币、就业安排、虚假咨询费。

## 2. 礼品与招待限额

| 类型 | 上限 | 报备 |
| --- | --- | --- |
| 接受供应商礼品 | 单次市价 ≤ 200 元，且为宣传品/日历等 | ＞200 须上交行政 |
| 接受宴请 | 工作餐合理档，禁止夜总会 | 预计 ＞500 元/人须部门负责人批准 |
| 给予客户礼品 | 单次采购价 ≤ 200 元/人，年度同一客户 ≤ 1,000 元 | OA 招待/礼品申请 |
| 给予客户宴请 | 见差旅与报销制度 | 事前申请 ≥2000 |

现金、红包、消费卡、游戏皮肤、油卡一律禁止。节假日礼盒须行政统一采购。

## 3. 利益冲突

员工直系亲属在供应商或客户任职须书面申报。不得参与该供应商选型评分。  
兼职：须书面批准；不得在竞争对手、客户处兼职。

## 4. 举报

邮箱 `compliance@nanjiren.local` 或总经理信箱。实名优先，匿名亦受理。禁止打击报复，违者解除劳动合同。  
经查实的贿赂，解除劳动合同并移送司法机关。

## 5. 销售特有

投标过程不得串标、伪造业绩。允许宣传的案例以 CRM 标记为准。承诺「关系费」由个人承担并视为严重违纪。

# 费用报销与付款申请流程

文档编号：XL-OA-004  
版本：V4.6  
生效日期：2026-02-10  
归口部门：财务管理部

## 1. 报销类型对照

| 流程名称 | 适用 | 禁止混用 |
| --- | --- | --- |
| 日常费用报销 | 办公、快递、低值易耗、市内交通、通讯、培训费 | 不可含差旅、采购资产、工资劳务 |
| 差旅报销 | 已批准出差 | 不可夹带采购设备 |
| 业务招待报销 | 客户餐饮、伴手礼（单次礼品 ≤ 300 元/人） | 不可报销酒水超过餐费 30% |
| 对公付款申请 | 供应商合同进度款、服务费、租金 | 不可对私（对私走报销或劳务） |
| 个人借款/还款 | 备用金 | 不可用于个人消费 |

每月报销截止：**次月 5 日 18:00**（遇节假日提前）。逾期纳入下月，连续两月逾期通报部门负责人。

## 2. 日常费用报销审批链

| 单笔金额（含税） | 审批链 |
| --- | --- |
| ≤ 1,000 | 直接上级 → 财务初审 |
| 1,000–5,000 | 直接上级 → 部门负责人 → 财务初审 |
| 5,000–20,000 | 上链 + 分管领导 → 财务经理 |
| 20,000–50,000 | 上链 + 财务总监 |
| ＞ 50,000 | 上链 + 总经理 |

多张发票拆单规避审批阈值的，财务有权合并计算并退回，情节严重按虚假报销追责。

## 3. 发票与附件规范

必须同时满足：

1. 增值税电子普通发票或专用发票，查验状态「正常」
2. 开票日期距提交不超过 180 天（专票认证期限以税务政策为准，财务会二次校验）
3. 货物/服务名称与事由一致，不得开「办公用品」笼统名目覆盖礼品
4. 专票抵扣须在备注填写项目编码或部门
5. 电子发票重复报销由系统票号查重拦截

发票丢失：普通发票可登报声明后由经办人+部门负责人双签「发票遗失说明」，同一人全年不超过 1 次；专票丢失按税务规定处理，一般不予报销。

## 4. 业务招待

- 事前：金额预计 ≥ 2,000 须走 **招待申请**（销售中心/客户成功部）
- 陪同人数：我方人数原则上不超过客户人数
- 禁酒：工作日午餐不得报销酒精类；晚餐酒精类不超过餐费 30% 且须客户在场
- 禁止：KTV、高尔夫、私人会所；禁止给客户个人微信红包后拿个人账单报销

## 5. 对公付款申请

路径：财务流程 → **付款申请**。

前置条件：关联合同编号 + 验收/进度确认单 + 发票（预付款合同约定可先付后票的，须法务条款引用）。

付款时间：每周二、周四 15:00 前完成审批的纳入当日批次；紧急付款（违约金风险）须财务总监加急。

供应商银行账户必须与主数据一致。不一致时先走 **供应商信息变更**，禁止在付款单手改账号。

预付款比例：

- 标准货物：≤ 30%
- 定制软件：按合同里程碑，首付款 ≤ 40%
- 超过上述比例：财务总监 + 分管领导会签

## 6. 退回常见原因

1. 成本中心选错（把交付费用记到销售）
2. 发票抬头错字、税号缺位
3. 无预算或预算科目用尽（须先走预算追加）
4. 招待缺少参与人名单与客户名称
5. 个人抬头的滴滴企业版与个人版混报

## 7. 到账

报销通过后 5 个工作日内打入工资卡。疑问联系财务共享 `finance.ssc@nanjiren.local`，工号需在邮件签名中注明。

# 合同审批、用印与档案流程

文档编号：XL-OA-006  
版本：V4.0  
生效日期：2026-03-20  
归口部门：法务合规部、行政管理部

## 1. 必须走合同审批的情形

满足任一条件即须发起 **合同审批**：

- 金额 ≥ 20,000 元
- 涉及个人信息、生产数据、源代码、驻场开发
- 租房、用工外包、投融资、NDA 以外的长期框架
- 客户侧模板且对我方责任条款有修改
- 分包、代理、渠道协议

纯 NDA 且使用公司 2026 标准模板、无修改：可走 **标准文件快速用印**，法务抽查。

## 2. 合同审批路径

路径：法务流程 → **合同审批**。

附件：合同正文 Word（可修订）+ PDF 清洁版、对方营业执照、授权委托书、关联立项/报价单、技术协议。

节点（按序）：

1. 承办人部门负责人（商务与毛利）
2. 财务部（收款账期、开票、质保金、税务）
3. 法务合规部（主体、违约、IP、数据、管辖）
4. 分管领导
5. 总经理（满足第 3 节阈值时）
6. 行政管理部排期用印

法务时效：标准模板无修改 **1 个工作日**；对方模板或重大修改 **2–4 个工作日**。紧急项目可加急，但不得跳过财务。

## 3. 总经理签发阈值

以下须总经理审批：

- 销售合同额 ≥ 150 万元，或账期 ＞ 90 天，或质保金 ＞ 10%
- 采购/分包合同额 ≥ 50 万元
- 无限责任、连带责任、不合适的管辖地（如仅对方所在地且排除仲裁）
- 排他代理、最惠国待遇、源代码托管

## 4. 用印申请

合同审批通过后自动带出 **用印申请**，也可单独发起（介绍信、资质复印等）。

| 印章 | 保管 | 用途 |
| --- | --- | --- |
| 公章 | 行政李楠 | 对外函件、资质、非合同类 |
| 合同专用章 | 行政 | 已审批合同 |
| 财务专用章 | 财务赵婉清授权出纳 | 发票、银行票据 |
| 发票专用章 | 财务 | 发票 |
| 法人章 | 总经理授权行政双锁 | 银行、工商、需法人名章文件 |
| 分公司章 | 各分公司行政 | 仅限该分公司经营范围 |

外带印章：必须「印章外带申请」，双人同行，当日归还，GPS 封签。原则上禁止公章外带至供应商处。

盖章方式：实体章或电子签章（上上签/e签宝企业账号）。电子章与实体章效力内部等同，但客户要求原件的须实体。

## 5. 档案

用印后 3 个工作日内将双章原件交行政档案室扫描，编号规则 `HT-YYYY-部门-流水`，例如 `HT-2026-XS-0188`。  
电子档入合同库，权限按销售/交付/财务只读。借阅原件须登记，最长 5 个工作日。

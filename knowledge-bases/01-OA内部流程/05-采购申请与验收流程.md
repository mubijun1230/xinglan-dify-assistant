# 采购申请、询价比价与到货验收流程

文档编号：XL-OA-005  
版本：V3.8  
生效日期：2026-05-12  
归口部门：供应链与采购部

## 1. 采购分类

| 类别 | 示例 | 承办 |
| --- | --- | --- |
| 生产/项目物料 | 工控机、传感器、扫码枪、服务器 | 采购部集中采购 |
| 非生产 | 办公家具、福利、市场物料 | 行政或采购 |
| 服务采购 | 实施分包、云资源、检测认证 | 采购 + 需求部门 |
| 软件许可 | CAD、数据库、安全软件 | 信息化部提需，采购下单 |

自行网购后报销：仅限 ≤ 500 元且目录外急用，全年不超过 3 次，否则必须走采购。

## 2. 采购申请

路径：供应链流程 → **采购申请 PR**。

必填：物料名称规格、数量、需求日期、预算科目、建议供应商（可选）、技术附件。

审批：

- ≤ 3,000：部门负责人 → 采购执行
- 3,000–20,000：部门负责人 → 采购经理 → 财务预算校验
- 20,000–100,000：上链 + 分管领导
- ＞ 100,000 或单一来源：上链 + 财务总监 + 总经理

## 3. 寻源规则

| 预估金额 | 方式 | 供应商数量 |
| --- | --- | --- |
| ＜ 5,000 | 询价或电商比价截图 | ≥ 1 家合格供应商即可 |
| 5,000–50,000 | 书面询价 | ≥ 3 家 |
| 50,000–200,000 | 竞争性谈判 / 比选 | ≥ 3 家，采购组织评分 |
| ＞ 200,000 | 招标（内部招标委员会） | ≥ 3 家投标，法务参与文件 |

单一来源须填写《单一来源说明》：专利/客户指定/兼容性/应急断供，由分管领导签字。客户指定品牌仍须做价格合理性说明。

评分维度（货物）：价格 40%、交期 20%、品质/质保 25%、服务 15%。软件服务类：方案 35%、价格 30%、案例 20%、商务 15%。

## 4. 合同与订单

中标/定标后：

1. 采购创建 PO，关联 PR
2. 金额 ≥ 2 万或涉及知识产权、驻场、数据安全的必须走 **合同审批**（见合同流程文档）
3. 标准《货物采购合同》模板（法务 2026 版）可走快速通道，法务 1 个工作日

## 5. 到货验收

路径：供应链流程 → **到货验收**。

- 办公类：行政仓管签收
- 项目现场设备：项目经理 + 客户现场代表（如合同要求）双签
- IT 资产：信息化部入库贴标签后发放
- 质保期起算：验收合格日，不是发货日

不合格：3 个工作日内开 NCR，采购负责退换，费用由供应商承担；影响项目里程碑的须同步 PMO。

## 6. 禁止行为

采购人员不得收受供应商礼金、购物卡；需求部门不得向供应商泄露其他厂家报价。一经查实，解除劳动合同并保留追究法律责任。

# 请假、销假与考勤异常处理流程

文档编号：XL-OA-002  
版本：V4.1  
生效日期：2026-01-01  
归口部门：人力资源部

## 1. 假期类型与额度

| 假别 | 编码 | 额度 | 是否带薪 | 证明材料 |
| --- | --- | --- | --- | --- |
| 年休假 | AL | 司龄满 1 年 5 天；满 10 年 10 天；满 20 年 15 天 | 是 | 无需 |
| 事假 | PL | 无固定额度，全年累计超 15 天影响绩效评级 | 否 | 说明即可 |
| 病假 | SL | 医疗期按劳动合同法 | 按司龄发放 60%–100% 基本工资 | 二级以上医院病历+发票 |
| 调休假 | CO | 来自加班兑换，当年 12 月 31 日前有效 | 是 | 关联加班单 |
| 婚假 | ML | 13 天（含法定 3 天+公司福利 10 天） | 是 | 结婚证 |
| 产假 | ML-M | 158 天（江苏口径：158 天） | 生育津贴与工资补差按财务规定 | 准生/生育服务材料、出院小结 |
| 陪产假 | PL-P | 15 天（须在配偶产假期间使用） | 是 | 出生医学证明或预产期证明 |
| 育儿假 | PL-C | 每年 10 天，子女不满 3 周岁 | 是 | 户口本或出生证明 |
| 丧假 | BL | 直系 5 天，配偶父母 3 天 | 是 | 关系说明 |
| 工伤假 | IL | 按认定结论 | 是 | 工伤认定书 |
| 产检假 | PL-E | 孕期累计 10 次，每次 0.5–1 天 | 是 | 产检预约单 |

年假最小单位 0.5 天。入职当年年假按剩余日历日折算，四舍五入到 0.5 天。

## 2. 请假如何走 OA

路径：南极 OA → 人事流程 → **请假申请**。

### 2.1 填写要点

- 开始/结束时间精确到上午/下午（09:00 / 13:30 为分界）
- 请假期间如有未完成审批，须指定工作代理人
- 项目制员工须选择所属项目编码（如 `PRJ-NBQC-2026-MES`），以便交付经理评估人力
- 出差期间请病假，差旅补贴自请假日起停发

### 2.2 审批链

| 时长 / 假别 | 审批链 |
| --- | --- |
| ≤ 1 天（年假/调休/事假） | 直接上级 |
| ＞1 天且 ≤ 3 天 | 直接上级 → 部门负责人 |
| ＞3 天 | 直接上级 → 部门负责人 → 分管领导 |
| 病假 ＞ 3 天 | 上述链 + 人力资源部备案 |
| 婚假 / 陪产假 / 育儿假 / 丧假 | 直接上级 → 人力资源部（核额度） |
| 产假 / 工伤假 | 直接上级 → 部门负责人 → 人力资源部 → 分管领导 |
| 一级部门负责人本人请假 | 分管领导 → 总经理（＞3 天） |
| 分公司人员 | 直线经理 → 分公司总经理；＞5 天加会签总部 HR |

### 2.3 时限

- 预请假：须在开始前至少 **0.5 个工作日** 提交（急诊病假可事后补单）
- 补单窗口：返岗后 **2 个工作日** 内，逾期视为旷工
- 产假须至少提前 15 个工作日提交，便于人力安排替岗

## 3. 销假

实际休假短于申请的，须在返岗当天发起 **销假**，系统按实际天数释放额度。  
多休部分：年假不足则自动转事假；事假不足则按缺勤扣款。

禁止「先休后补且无急诊证明」超过 2 次/年，第三次起按严重违纪记过。

## 4. 考勤异常处理

钉钉打卡规则：上班 09:00，下班 18:00，午休 12:00–13:30。弹性 30 分钟（最迟 09:30 到岗，当晚补足工时）。

路径：人事流程 → **考勤异常申诉**。

| 异常类型 | 处理 |
| --- | --- |
| 忘记打卡 | 每月最多申诉 2 次，需直接上级证明在岗 |
| 外勤未打卡 | 须关联当日已通过的出差/外勤单 |
| 系统故障 | 信息化部出故障公告后，批量修正，无需个人申诉 |
| 迟到 1–30 分钟 | 当月 3 次内口头提醒；第 4 次起每次扣 50 元餐补 |
| 迟到 ＞30 分钟或早退 | 按事假 0.5 天计，不足则扣款 |
| 旷工 | 1 天扣 3 倍日工资；连续 3 天或年度累计 5 天解除劳动合同 |

驻场客户现场人员以客户门禁或项目经理日报为准，须在 OA 选择「驻场考勤方案」。

## 5. 与加班、出差的关系

- 出差期间默认出勤，无需打卡，但须有已通过差旅申请。
- 周末在客户现场加班，须单独走加班流程，不能仅靠差旅单自动生成加班。
- 调休假优先于年假使用（系统强制）。

## 6. 示例

销售工程师王磊拟于 2026-08-25 至 2026-08-27 休年假 3 天：  
提交请假申请 → 直属经理刘思远团队的区域经理审批 → 销售中心负责人会签（因 ＞1 天）→ HR 系统扣减年假额度 → 钉钉考勤同步。

# 南极业务助手 · 工作流

Chatflow，模型 DeepSeek-V4-Flash（关闭 thinking）。

```text
输入 → 意图
  oa       → 检索 OA+制度 → 空则拒答 / 有则结论-依据-办理路径
  project  → 检索工程项目 → 空则拒答 / 有则结论-依据-待办
  sql      → 生成 SELECT → 网关（重试 2 次）→ 200 原样正文 / 否则失败文案
  chitchat → 能力说明
  oos      → 职责外文案
```

- 支付金额、渠道、类目、导出、直方图 → sql（表 `nanjiren_cate_date`）
- 工程名称、项目编号、负责人、里程碑 → project
- 请假报销用印等 → oa
- 一句里流程+取数：主诉求分流；金额优先 sql

模型不直连库。网关：仅 SELECT/WITH、禁 UNION/JOIN/多语句、表白名单、LIMIT、会话只读。

验收：请假超 3 天谁批；日销仓负责人是谁；2025 抖音内衣支付金额；按渠道汇总导出 Excel。
